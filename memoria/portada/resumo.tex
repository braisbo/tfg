\begin{abstract}
  En este trabajo se ha desarrollado un sistema de realidad aumentada que permite visualizar modelos anatómicos 3D superpuestos sobre marcadores fiduciarios. El principal reto consistía en conseguir un seguimiento preciso de objetos 3D complejos, para lo cual se diseñó un marcador fiduciario cúbico basado en ArUco. El proceso abarca desde la obtención de volúmenes 3D a partir de tomografías computarizadas hasta la impresión 3D de las piezas anatómicas, incluyendo la implementación de algoritmos de visión artificial para el seguimiento en tiempo real. La aplicación resultante integra las librerías OpenCV, ArUco y OpenGL, logrando mantener el alineamiento entre el modelo virtual y el marcador físico. Esta propuesta constituye una alternativa de código abierto frente a los sistemas comerciales actuales y sienta las bases para futuros desarrollos en entornos de realidad extendida.


  \vspace*{25pt}
  \begin{segundoresumo}
    This project embodies the development of an augmented reality system that enables the visualization of 3D anatomical models overlaid on physical fiducial markers. The main challenge was achieving precise tracking of complex 3D objects, which led to the design of a cubic fiducial marker based on ArUco. The process covers everything from obtaining 3D volumes from computed tomography scans to 3D printing of anatomical pieces, including the implementation of computer vision algorithms for real-time tracking. The resulting application integrates OpenCV, ArUco, and OpenGL libraries, successfully maintaining stable alignment between the virtual model and the physical marker. This proposal represents an open-source alternative to current commercial systems and lays the groundwork for future developments in extended reality environments.
  \end{segundoresumo}
